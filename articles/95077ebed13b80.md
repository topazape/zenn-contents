## はじめに

あなたは架空の VOD サービスのデータサイエンティストです。

メディアプランナーから「過去 90 日間に韓国ドラマまたはラブロマンスを見たユニークユーザー (UU) は何人ですか」と聞かれたとします。UU は、想定したターゲティングセグメントで広告キャンペーン予算を消化できるかどうかを判断する材料になるため、重要な数字のひとつです。頻繁に聞かれる数字のため、正確かつ低コストでどんなパターンでも素早く UU を算出できると嬉しいです。

ユーザーの視聴ログをデータベースから全件取得できるなら、条件に合う視聴者を直接重複を除いてカウントすることで UU を算出できます。しかし、ジャンルの組み合わせごとに大規模な個票データをスキャンすると、そのたびにクエリコストがかかります。これを避けるために、ジャンル間の同時分布をあらかじめ近似し、その分布から UU を計算することを考えます。

このような状況をどうやってモデル化すると良さそうでしょうか。

## Latent Class Analysis

今回は、その近似モデルとして潜在クラス分析 (Latent Class Analysis; LCA) を使います。LCA は、潜在的な集団を見つけて解釈するために使われることが一般的ですが、ここでは多変量二値データの同時分布を近似するために用います。推定されたパラメータを用いれば、大量のデータをカウントせずともジャンルの組み合わせごとの UU を計算できます。

例として、$n = 50{,}000$ 人の視聴者パネルを考えます。各視聴者について、$J = 16$ ジャンルの視聴有無が二値で記録されており、同じ視聴者が複数のジャンルを見ている場合を考えます。空でないジャンルの組み合わせは理論上 $2^{16} - 1$ 通りありますが、実務で扱う範囲として、近似精度の評価は最大 4 ジャンルの組み合わせを考えておけばいいとします。

ジャンル集合 $S$ の UU は、既知の母集団サイズを $M$ とすると、

$$
  \operatorname{UU}(S) = M \cdot P\!\left( \bigcup_{j \in S}\{X_j = 1\} \right)
$$

と表せます。以下では、この和集合確率を LCA の推定結果から閉形式で求め、その近似精度を検証します。

## 合成データの生成

ジャンル間の現実的な共起関係を再現するため、視聴傾向の近いジャンル同士に相関を持たせます。

視聴者 $i$ は、4 次元の潜在因子 $\mathbf{f}_i \sim N(\mathbf{0},\mathbf{I}_4)$ を持つものとします。この潜在因子を条件とすると、各ジャンルの視聴有無は独立に生成されることになります。

$$
  P(X_{ij} = 1 \mid \mathbf{f}_i)
  = \sigma\!\left( \alpha_j + \boldsymbol{\lambda}_j^\top\mathbf{f}_i \right),
  \qquad
  \sigma(x) = \frac{1}{1 + e^{-x}}
$$

第 1 因子は犯罪・ドキュメンタリー、第 2 因子は恋愛、第 3 因子はアニメ・SF・ファンタジー・ホラーの視聴傾向にそれぞれ影響を与えます。第 4 因子は全ジャンルに共通する視聴量を表し、すべてのジャンルに弱く影響します。視聴量の多いユーザーほど幅広いジャンルを見るため、ジャンル全体に正の相関が生じます。ただし、このモデルで直接生成するのはジャンルごとの視聴有無であり、視聴時間ではありません。

データ生成には、有限混合モデルではなく連続因子モデルを用います。したがって、後で推定に用いるベルヌーイ混合モデルは、真のデータ生成過程とは一致しないことになります。実データも特定の有限混合分布に厳密に従うとは限らないため、その状況を想定した設定です。

$\alpha_j$ は、各ジャンルを視聴したユーザーの割合が 12% から 60% になるよう、シミュレーションで調整しました。モデルの推定に使う学習データと、$K$ の選択に使うバリデーションデータは、それぞれ 50,000 人です。最終的な近似精度は、同じ生成過程から独立に作成した 2,000,000 人のテストデータで測定します。

## 独立近似による和集合の過大推定

UU を推定するのに最も単純な方法は、学習データから得た各ジャンルの視聴者割合 $\hat p_j$ を使い、ジャンル間の視聴有無を互いに独立とみなすことです。このとき、ジャンル集合 $S$ のいずれかを視聴したユーザーの割合は、

$$
  \hat P_{\mathrm{indep}}\!\left( \bigcup_{j \in S}\{X_j = 1\} \right)
  = 1 - \prod_{j \in S}(1 - \hat p_j)
$$

と推定できます。

しかし、ジャンル間の視聴傾向は生成過程から独立ではありません。韓国ドラマを見るユーザーはラブロマンスも見る傾向が強いため、二つの視聴者層の重複は独立を仮定した場合より大きくなります。その結果、独立近似では重複を過小評価し、少なくとも一方を見たユーザーの割合を過大評価します。

学習データから計算した各ジャンルの視聴者割合、独立近似による和集合、バリデーションデータで実測した和集合を Table 1 に示します。

## 潜在クラス分析による同時分布の近似

独立近似は和集合確率を簡単に計算できますが、ジャンル間の共起を表現できません。$K$ クラスの LCA、すなわちベルヌーイ混合モデルを使えば、計算のしやすさを保ちながら共起も表現できます。

$$
  P(\mathbf{x})
  = \sum_{k=1}^K\pi_k\prod_{j=1}^J \theta_{jk}^{x_j}(1 - \theta_{jk})^{1-x_j},
  \qquad
  \mathbf{x} \in \{0,1\}^J
$$

$\pi_k$ はクラス $k$ の構成比、$\theta_{jk}$ はクラス $k$ に属する視聴者がジャンル $j$ を見る確率です。各クラスの中ではジャンル間の視聴有無を独立と仮定しますが、複数のクラスを混合することで、母集団全体の依存関係を表現できます。ここでは、{flexmix} の EM アルゴリズムで推定します。

LCA のパラメータ数は $K(J + 1) - 1$ です。独立モデルの 16 個より多い一方、飽和モデルに必要な $2^{16} - 1 = 65{,}535$ 個よりはるかに少なくなります。$K = 1$ は独立モデルのパラメータ数と一致し、$K$ を増やすほど複雑な共起関係を表現できます。

ここでは、潜在クラスそのものには解釈を与えません。混合モデルを $P(\mathbf{x})$ の確率分布を近似するために使い、ジャンルの組み合わせごとの UU 推定精度で評価します。

## 任意の条件に対する UU の計算

クラス $k$ を条件とすると、各ジャンルの視聴有無は独立です。視聴ありとするジャンルの集合を $A$、視聴なしとするジャンルの集合を $B$ とすると、

$$
  P\!\left( \bigcap_{j \in A}\{X_j = 1\}\; \cap \;\bigcap_{j \in B}\{X_j = 0\} \right)
  = \sum_{k=1}^K\pi_k \prod_{j \in A}\theta_{jk}\prod_{j \in B}(1 - \theta_{jk})
$$

となります。集合 $S$ のいずれかのジャンルを見た確率は、$S$ に含まれるジャンルを一つも見ていない確率の余事象として、

$$
  P\!\left( \bigcup_{j \in S}\{X_j = 1\} \right)
  = 1 - \sum_{k=1}^K\pi_k\prod_{j \in S}(1 - \theta_{jk})
$$

で求められます。また、「アニメを見たがホラーは見ていない」のように積集合や否定を含む条件も同じ形で計算できるため、一つのモデルでさまざまな集計条件に対応できます。

## バリデーションデータに基づくクラス数の選択

$K \in \{1,2,3,4,6,8,12,16\}$ を比較してみます。各モデルは 50,000 人の学習データだけで推定します。評価対象は、2-way（2 ジャンルの和集合、120 通り）、3-way（3 ジャンルの和集合、560 通り）、4-way（4 ジャンルの和集合、1,820 通り）のすべてとします。それぞれについて和集合確率を推定し、バリデーションデータでの実測値と比較します。1-way は学習データの周辺割合をそのまま使えるため、評価対象から除きます。

バリデーションデータでの実測値を $u_q$、モデルによる推定値を $\hat u_{q,K}$ とします。$K$ の選択には、2-way、3-way、4-way の全組み合わせについて、確率尺度で計算した RMSE を使います。各組み合わせを同じ重みで評価するため、組み合わせ数の多い way ほど全体の RMSE に占める重みも大きくなります。全組み合わせ数を $Q$ とすると、評価指標は次のようになります。

$$
  \operatorname{RMSE}(K)
  = \sqrt{\frac{1}{Q}\sum_{q=1}^{Q}(\hat u_{q,K} - u_q)^2}
$$

RMSE は $K = 8$ まで低下し、それ以降の改善は小さくなっています。ここでは、近似精度とモデルの複雑さのバランスから $K = 8$ を採用することにしました。

## テストデータによる近似精度の評価

選択した $K$ を固定した後、独立に生成した 200 万人のテストデータで近似精度を評価します。

合成データでも、有限の標本から計算した和集合確率は、生成のたびにわずかに変動します。テストデータを 200 万人まで増やすことで、この変動を小さくし、テストデータでの実測値を母集団の和集合確率に近づけます。これにより、観測された誤差の大部分を、テストデータの偶然のばらつきではなくモデルの近似誤差として評価できます。

## まとめ

複数のターゲティング条件に同じユーザーが含まれるとき、当たり前ですが、条件ごとの UU を足し合わせるだけでは全体の UU を正しく求められません。ジャンルの組み合わせを同時分布としてモデル化しておけば、ユーザー単位のデータを毎回集計し直すことなく、この重複を織り込んだ推定ができます。

ここで潜在クラス分析を使った目的は、オーディエンスの背後にあるセグメントを発見して解釈することではありません。複雑な同時分布を、少数のパラメータで扱える形に近似するためです。そのため、クラス数も情報量規準ではなく、実際に利用する UU 集計のバリデーション誤差を基準に選びました。

一度モデルを推定すれば、あとはそのパラメータだけで、任意のジャンルを組み合わせた UU を計算できます。この手法の実務上の利点は、重複を含むさまざまなオーディエンス条件へ繰り返し利用できる集計の仕組みを用意できる点にあります。

## 実装例

モデル推定後の集計に必要なのは、クラスの構成比 $\hat\pi_k$ と、クラス別・ジャンル別の視聴確率 $\hat\theta_{jk}$ だけです。

```r
library(tidyverse)
library(flexmix)

set.seed(2029)
sf <- stepFlexmix(
  X_train ~ 1,
  k = selected_k,
  nrep = 3,
  model = FLXMCmvbinary(),
  verbose = FALSE
)
fit <- getModel(sf, which = as.character(selected_k))

pi_hat <- prior(fit)
theta_hat <- parameters(fit)

uu_union <- function(pi_hat, theta_hat, S) {
  1 - sum(pi_hat * apply(1 - theta_hat[S, , drop = FALSE], 2, prod))
}

s_pair <- c("K-Drama", "Romance")
S <- match(s_pair, colnames(X_train))
uu_union(pi_hat, theta_hat, S)
```
